# 考公刷题机

国考/省考刷题网页版：国考真题（行测 2000–2025、申论 2000–2025）+《行测5000题》+《申论100题》，支持科目切换、顺序/随机/题型/模拟考试/错题/收藏练习、刷题模式与学习模式、计时器、历史记录，以及申论主观题按评分细则判分。手机/平板可直接使用，支持“添加到主屏幕”和离线刷题。

**在线使用：** https://wunian-10086.github.io/kaogong-shuati/

## 使用

- 电脑：打开上面的网址即可；
- 手机/平板：打开网址 → 浏览器菜单「添加到主屏幕」，像 App 一样使用（首次打开后离线可用）；
- 数据：答题记录、错题本、收藏保存在各自设备浏览器本地，不联网、不上传。

## 更新

在电脑端刷题机里重新「导出分享版」，然后重新运行 `部署到GitHub-Pages.bat` 即可覆盖发布。
